# ☕ Coffee-Borcelle Web Application

**Coffee-Borcelle** is a sleek, responsive web platform engineered to bridge artisan coffee craftsmanship with digital accessibility. Built with **HTML5** and **CSS3**, this application provides a high-fidelity digital storefront featuring an interactive menu, promotional highlights, customer reviews, and a direct contact system.

---

## ✨ Features

* **Interactive Menu Grid:** Showcases hot and cold specialty beverages with dynamic grid layouts.
* **Responsive Architecture:** Fully optimized for smooth navigation across desktop, tablet, and mobile devices.
* **Special Offers Section:** Clean visual cards designed to highlight active café promotions and discounts.
* **Customer Testimonials:** Dedicated social proof area displaying customer reviews and star ratings.
* **Accessible Contact Form:** Integrated user communication form paired with location and operating hour details.
* **Modern Aesthetic:** Uses a warm "Espresso & Cream" visual palette with optimized typography for high scannability.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3
* **Typography:** Google Fonts (*Playfair Display*, *Roboto*)
* **Version Control:** Git, GitHub
* **Deployment:** GitHub Pages
